# Global currencies, countries and on-device AI · 24 September 2026

Branch `claude/global-ai-20260924`. The user's decisions are recorded in memory and repeated here. They are:
- platform on-device AI;
- foreign money converted to the single ledger currency;
- English and Arabic UI, with locale-aware numbers, dates and statements;
- best-effort auto-post for unproven formats, with guardrails.

## What changed

- **On-device AI.** A new `modules/wafra-on-device-ai` module uses Apple Foundation Models (iOS 26+) and Gemini Nano through ML Kit GenAI (supported Android phones).
  - Ask Wafra uses it only to choose one closed tool. Wafra computes every figure.
  - Category suggestions need an explicit tap to apply.
  - Wafra makes no network request for platform AI.
  - The 37 MB E5 download is off by default, and old E5 files are purged.
- **Money formatting.** Numbers are grouped and separated for the device region, including Indian lakh grouping and decimal comma. Typed amounts are parsed per locale, and ambiguous input is refused. The currency symbol sits where the locale expects it. Magnitude thresholds scale by currency. The region comes from the device Region, not the language.
- **Foreign currency on any ledger.**
  - The original amount is kept in its own ISO exponent.
  - Conversion uses dated reference rates from Frankfurter (central-bank data). A request carries only two currency codes and a date. A rate is never invented; without one, the purchase waits in Review.
  - When an alert states the card's charged amount, that amount wins inside a plausibility band.
  - The Gulf parser no longer drops currencies outside its offline table.
- **Countries.**
  - Every ISO 3166 country can be chosen in onboarding and Settings. It defaults from the device Region.
  - Nobody outside AE/SA is silently given UAE bank packs any more.
  - Date order follows the country.
  - Statements read decimal-comma amounts when the file proves that convention, and month names in 11 languages.
  - Forwarding addresses can carry the ledger currency and date order, but the app has no entry point for them yet.
  - This needs the additive migration `server/migrations/2026-09-24-email-statement-locale.sql`, which the normal deploy step runs.
- **World packs.** Review-only packs for Canada, Australia, Brazil, Mexico and Singapore, with 38 standard-derived public fixture rows.
  - One certification rule fires: the ANZ Osko credit.
  - A Chase "did you make this purchase?" fraud check is no longer posted.
- **Best-effort auto-post.** Clear, completed, single-amount alerts from unproven formats are auto-added with an "Auto-added — check" marker.
  - "Looks right" clears the marker. "Undo — remove" asks for confirmation and records a tombstone.
  - An "Auto-added to check" filter is available, and a Settings toggle (default on) switches the behaviour off.
  - Pending, hold, authorisation, request, declined, OTP, promotional, balance, statement and future-dated messages are never posted, in eight languages.
  - A shared symbol (`$`, `¥`, `Rs`) resolves through the bank's route first, then through the user's country.
  - UAE/SA senders and routes keep the strict path. iOS live capture stays review-only.

## Verification

- `tsc` is clean and the full JS suite exits 0, including the server suites.
- The native history, live-capture and queue-signal host suites pass.
- The iOS on-device AI module was typechecked against the iOS 26.1 SDK at iOS 15.1 and 26.0 targets. The Kotlin was compiled with kotlinc 2.1.20 against the ML Kit classes.
- Every stream was reviewed independently. The final integration review found one blocker, now fixed with regression tests that fail without the fix: a `$` alert from a foreign bank was read in the user's own currency.

## Known limits

- **Not run on a real device.** Nothing here has run on a device. On-device AI needs an Apple Intelligence iPhone and a Gemini Nano phone. Symbol placement and Indian grouping on Hermes are also unverified.
- **Undo tombstones.** For bank-app notifications without a stable source id, the undo key uses the converted ledger amount, so a different cached rate could let an undone notification return once.
- **Parsing coverage.** Only UAE/SA are proven. Everywhere else is best-effort or review-only. CSV column headers are English/Arabic only.
- **Symbol-sharing brand collisions** can route a New Zealand or Hong Kong `$` to Australia or Singapore.
- **Play Data Safety** must be updated for ML Kit before an Android store submission.
