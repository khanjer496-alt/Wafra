## iOS Shortcut review

### Future bank SMS

The published Wafra Local Capture Shortcut is https://www.icloud.com/shortcuts/96f93402213144e8885db33f48fc6168 . Its **11 actions** match the canonical source and Apple's signing status is APPROVED. No Shortcut replacement was necessary for this candidate.

The user configures a personal Message automation for the bank senders they select, set to Run Immediately. The native action stages messages locally; the app processes the protected queue when opened. A harmless setup proof is distinct from successfully receiving a real bank alert.

The sender alias registry is empty, but current `src/lib/local-message-record.ts` falls back to the shared bank-market detector. The empty registry does **not**, by itself, disable capture. Older handoff documentation claiming otherwise is stale.

### Past-message history

The published Wafra History Import Shortcut is https://www.icloud.com/shortcuts/2869584d40ed454691cf3f916cbee158 . Its **111 actions** match the canonical production source and Apple's signing status is APPROVED.

The production graph uses two bounded 1,500-message halves with a GUID-overlap check, supporting at most **2,999 retained messages**. It requires iOS 26 or newer; keep the device unlocked and Shortcuts open during history import. This is not unlimited or silent inbox access.

The larger adaptive date-window/history experiments are not the published production graph and were **not enabled** for this beta. The review did not establish completion of uncommitted work on a developer's Mac.

The comparison normalized only known Apple share metadata (including the added Watch surface). Action parameters, control flow, inputs and outputs were not normalized away.
