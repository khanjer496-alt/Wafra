# App Store header and search-results art

Generated by `scripts/render-appstore-promo.mjs` from the seeded demo ledger
(synthetic data only), captured in light mode at the 6.9" logical width. The
phones show the real Home, Spending, Bills and Accounts screens with an iOS
status bar added above them. Rerun the script after any visible UI change.

## Markets

One folder per market. Each is rendered from its own demo export
(`EXPO_PUBLIC_WAFRA_DEMO_MARKET`, see `DemoMarket` in `src/lib/seed.ts`):

| Folder | Language | Ledger | Banks and merchants | Capture shown |
| --- | --- | --- | --- | --- |
| `global/` | English | USD | Generic checking and Visa; Whole Foods, DoorDash, Uber, Target | Entered by hand |
| `ae/` | English | AED | Emirates NBD, FAB; Carrefour, Talabat, Careem, noon | Bank messages |
| `sa/` | Arabic (right-to-left) | SAR | Al Rajhi, SNB; Panda, HungerStation, Jarir, Nahdi | Bank messages |

Global rows are all entered by hand. Automatic bank-alert posting is
launch-tested only for UAE and Saudi banks; other markets run the
universal parser on a best-effort or review basis
(`docs/universal-parser-rollout.md`). Store art must not show certified
capture there.

App Store localizations are per language, not per country. `global/` fits
the default English localization, `sa/` fits the Arabic localization, and
`ae/` belongs on a UAE custom product page or a UAE-targeted test.

## Safe area

Apple crops the header to narrower aspect ratios on smaller devices and
overlays the app icon, name and Get button along the bottom. The headline and
app name stay inside the centre 60% of the width and the top 72% of the
height. Phones may bleed off the bottom edge because that area is overlay.

## Content rules

- No price, trial or subscription terms in the art.
- No "AI" wording.
- Amounts are sample data in each market's currency, not a coverage claim.
- Arabic art is the English layout mirrored, rendered with an `ar-SA` device
  locale so the app's own UI is Arabic.
- The app has no photos of people, so the art uses no people imagery. Adding
  stock photography would show something the app does not.
- Check Apple's current header and search-visual specifications at upload
  time. Apple revises them when the hardware line changes.

## A/B pairing

Run the header and search tests separately so each result means one change:

1. Product Page Optimization: `header-a` (control) against `header-b`.
2. Search visual: `search-a` (control) against `search-b`.

## Regenerating

```sh
for m in global ae sa; do
  EXPO_PUBLIC_WAFRA_E2E_DEMO=1 EXPO_PUBLIC_WAFRA_DEMO_MARKET=$m \
    npx expo export --clear --platform web --output-dir /tmp/wafra-$m
  node scripts/e2e/serve.mjs /tmp/wafra-$m 8126 & SERVER=$!
  node scripts/render-appstore-promo.mjs --market $m
  kill $SERVER
done
```

The script stops if the served export shows a different market's currency.
Clear Metro's cache between exports (`--clear`), because it is not keyed by
`EXPO_PUBLIC_*` values.
