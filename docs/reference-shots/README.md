# Reference screenshots for the blind review loop

Drop competitor screenshots here, named `<app>-<screen>.png`.

Screens worth capturing (match Wafra's surfaces):
- `<app>-home.png`        — dashboard / balance hero
- `<app>-transactions.png`— transaction list, grouped by day
- `<app>-detail.png`      — a single transaction detail sheet
- `<app>-analytics.png`   — spend breakdown / charts
- `<app>-budgets.png`     — budget or limit tracking
- `<app>-wallet.png`      — accounts / cards list
- `<app>-empty.png`       — any empty or first-launch state

Apps worth pulling from: Revolut, Monzo, Wise, Cash App.
Both light and dark are useful; suffix `-light` / `-dark` if you capture both.

Anything you drop here gets used for a blind A/B against the equivalent
Wafra screen. Partial sets are fine — one app, three screens still helps.
